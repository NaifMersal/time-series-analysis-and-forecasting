A. The benchmark floor

Ch 5.1–5.2 · Simple, strong baselines

Four essential benchmarks

  • Mean — Average of all historical observations
  • Naive — Last observed value (\(\hat{y}_{T+h} = y_T\))
  • Seasonal Naive — Same season from previous year (\(\hat{y}_{T+h} = y_{T+h-m}\))
  • Drift — Last value plus average historical trend slope

Always fit these 4 first. On many series, Seasonal Naive is tough to beat.

Why benchmarks are non-negotiable

  • Objective Evidence — proves the complex model adds value
  • Sanity Check — catches complex ML models losing to naive rules
  • Scale Baseline — provides a standard denominator for errors (MASE)
  • Fast — takes just a few lines of code

B. Residuals

Ch 5.3–5.4 · Has the model finished?

Fitted values vs. Forecast errors

Residual (\(e_t\)): Error on in-sample training data (one-step ahead)

\[e_t = y_t - \hat{y}_{t|t-1}\]

Crucial Distinction

  • Residuals = In-sample training errors (flattering)
  • Forecast Errors = Out-of-sample holdout errors (honest)

Properties of good residuals

Essential

  1. Uncorrelated (\(r_k \approx 0\))
    \(\rightarrow\) No signal left behind
  2. Zero Mean (\(\bar{e} = 0\))
    \(\rightarrow\) Unbiased forecast

For Valid Intervals

  1. Constant Variance
    \(\rightarrow\) Homoscedastic
  2. Normally Distributed
    \(\rightarrow\) Gaussian intervals valid

# Dataset: Victorian retail takeaway turnover in-sample fitted values (fv = train merged with StatsForecast fitted values)
resid = fv["y"] - fv["SeasonalNaive"]
fig, axes = P.residual_diagnostics(resid, ds=fv["ds"],
                                   title="Seasonal Naive — Residual Diagnostics")
  • Residuals show expanding variance over time
  • Autocorrelation spikes remain outside bounds \(\rightarrow\) Signal left uncaptured

The Ljung-Box Test

Statistically tests if the first \(\ell\) autocorrelations are jointly zero:

\[Q = T(T+2)\sum_{k=1}^{\ell}\frac{r_k^2}{T-k}\]

  • Small \(p\)-value (\(p < 0.05\)) \(\rightarrow\) Significant autocorrelation \(\rightarrow\) Model incomplete
  • Large \(p\)-value (\(p \ge 0.05\)) \(\rightarrow\) Residuals are indistinguishable from white noise

Rule of thumb: use lag l=10 for non-seasonal data, l=2m for seasonal data.

C. Prediction intervals

Ch 5.5 · Quantifying uncertainty

Point forecasts vs. Range forecasts

Point Forecast

“Demand will be 340 units.” - Guaranteed to be wrong - Hides operational risk

Interval Forecast

“Demand: [300, 380] with 80% confidence.” - Actionable for safety stock - Slices uncertainty honestly

Decisions like staffing buffers, warehouse capacity, and safety inventory depend directly on the interval width.

Interval calculation

For a 1-step forecast with residual standard deviation \(\hat{\sigma}\):

\[\hat{y}_{T+1|T} \pm c\,\hat{\sigma} \qquad (c = 1.28 \text{ for } 80\%,\; 1.96 \text{ for } 95\%)\]

For horizon \(h\), uncertainty accumulates:

\[\hat{\sigma}_h = \hat{\sigma}\sqrt{h}\]

Note

Uncertainty widens with \(\sqrt{h}\) — rapid growth early on, decelerating at longer horizons.

Why one test window is misleading

On a single small test set (\(n = 24\)), coverage error is large:

\[\text{SE} = \sqrt{\frac{p(1-p)}{n}} = \sqrt{\frac{0.8 \times 0.2}{24}} \approx \pm 8\% \quad (\pm 16\% \text{ at } 95\% \text{ CI})\]

A nominal 80% interval could easily measure anywhere from 64% to 96% on a single 24-point holdout by chance alone.

To properly measure coverage, we must evaluate across multiple rolling test origins.
